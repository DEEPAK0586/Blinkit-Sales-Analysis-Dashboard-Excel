# 🛒 Blinkit Sales Analysis Dashboard – Excel

## 📌 Project Overview
This project focuses on analyzing Blinkit's sales data using Microsoft Excel to identify sales trends, product performance, and outlet performance.

An interactive Excel dashboard was developed to transform raw sales data into meaningful business insights using PivotTables, PivotCharts, formulas, slicers, and filters.

## 🎯 Project Objectives
- Analyze overall sales performance.
- Identify top-performing outlet types.
- Understand product category performance.
- Analyze sales trends across different outlets.
- Build an interactive dashboard for business reporting.

## 📊 Dataset Information
- **Dataset:** Blinkit Sales Dataset
- **Records Analyzed:** 1,200
- **Tool Used:** Microsoft Excel

## 🛠️ Tools & Techniques
- Microsoft Excel
- Data Cleaning
- Data Preparation
- PivotTables
- PivotCharts
- Excel Formulas
- Slicers and Filters
- Interactive Dashboard Development

## 📈 Dashboard Features
- Sales performance analysis
- Outlet-wise sales analysis
- Product category analysis
- Sales trend visualization
- Interactive filters and slicers

## 🔍 Key Insights
- Identified top-performing outlet types.
- Analyzed high-revenue product categories.
- Explored sales trends across different outlets.
- Compared business performance using interactive visualizations.
